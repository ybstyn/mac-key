The bundled native helper is a modified build of Cockpit Tools. Its original
account-switch and instance-launch command modules remain the implementation
of those operations. The API transport adapter adds authenticated same-user
IPC and the Apple Silicon package integrates the helper with the API launcher.
Corresponding modified source is included in the build repository.
