# API 1.0.17 Mac 对齐补丁

基准是公开 Mac 工程的 `bee57bcf35ea911b38e3db7594114ef3033a9242`（产品版本 1.0.15）。Windows 差异依据已交付的 `API_1.0.15_source.zip` 和 `API_1.0.17_source.zip`，没有把 Windows exe 当作 Mac 程序使用。

| Windows 1.0.16 / 1.0.17 变化 | Mac 处理 |
| --- | --- |
| Gemini / Claude 双 Key，任意一个可以进入 | 主入口提供两个独立输入框；对话内沿用双 Key 管理窗 |
| 先全部校验，再原子保存 | 单次 Keychain 加密文件事务；错误 Key 或加密失败保留原值 |
| 添加平台保留历史；替换 Key 隔离历史 | Mac 新增批量桥接，保留当前空间或启动独立空间；未填写平台及 GPT Key 独立保留 |
| 未读回复、已读记录、成功回复投影 | 共用当前 1.0.17 聊天源码；已读记录按本地会话空间持久化 |
| 侧栏平台选择、可搜索模型目录及会话菜单 | 共用当前 1.0.17 组件，不复制第二套界面 |
| 会话确认删除、归档及禁止删除正在回复的目标 | 复用 Cherry 正式归档生命周期，其他会话仍可操作 |
| Windows DWM 不透明绘制与完整恢复 | Mac 保留原窗口、资源和不透明主背景，首次绘制完成后显示；使用 Mac 窗口与合成器 |
| Windows 注册表代理例外 | Mac 树莓派请求走应用内直连，保留用户系统代理和 VPN |
| Windows 树莓派自动更新 | 按用户要求，Mac 继续取消自动更新、检查更新及下载设置 |

Mac 自身修补还包括：统一聊天 `out` 资源目录；菜单栏使用 PNG 图标；移除受管聊天中未启用的协议导航和助手菜单调用；为原生窗口按钮留出标题栏空间；测试正确匹配组合后的界面标记。

源码补丁通过 `git apply --check` 验证。安装包另行在 GitHub 的 Apple Silicon Mac 上编译，只有匹配版本的原生 / Keychain / 聊天运行报告全部通过，才作为试用包交付。

隔离测试使用随机测试 Key 和本机模拟网关，验证双 Key 原子保存、流式回复中的交互、未读提示、重启历史、用户隔离及 Mac 批量桥接。不连接家中的树莓派、不使用真实账号、不自动发起收费对话。

目标是 Apple Silicon / macOS 13 或更新版本。初版使用 ad-hoc 签名，尚未 Apple Developer ID 公证；真实树莓派对话和官方客户端切换仍需在目标 Mac 上验收。
